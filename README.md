# The Daily Grind Café — Next.js

A modular, responsive café website built with Next.js App Router, React and CSS Modules.

## Requirements
- Node.js 20.9 or newer (Node.js 22 LTS recommended)
- npm

## Run locally
1. Open this folder in Antigravity.
2. Open the integrated terminal: `Ctrl + backtick`.
3. Check Node and npm:
   ```bash
   node -v
   npm -v
   ```
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```
6. Open http://localhost:3000

Stop the server with `Ctrl + C`.

## Production check
```bash
npm run build
npm run start
```

## Important before publishing
- Replace the example café address, phone number and email.
- Replace `https://www.thedailygrind.example` in `app/layout.js`, `app/robots.js` and `app/sitemap.js` with the real production domain.
- Connect the contact form to an API route, email provider or booking system. It currently validates input and displays a demo confirmation only.
- Update menu items and prices in `data/menu.js`.
- Add real café photography. The current image URLs are remote Unsplash images.
- Add real social profile links and verify business details.

## SEO included
- Per-page title and description metadata
- Shared title template and Open Graph metadata
- Twitter card metadata
- Semantic page landmarks and headings
- Descriptive image alt text
- `robots.txt` and XML sitemap generated by Next.js
- Canonical production host configured through `metadataBase` (replace the example domain)

This project is a frontend website. It does not include a database, CMS, online ordering or live table reservations.
